전체 백업에는 원본 지식·리비전·입력 로그·검사 결과가 포함됩니다. 원본 JSON 내보내기와 다릅니다.




복원은 현재 DB를 교체합니다. 복원 전 현재 상태를 data/backups/에 자동 백업합니다. 같은 DB를 사용하는 다른 서버는 먼저 종료하세요.
